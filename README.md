# ☕ Pomodoro App

Une application Pomodoro minimaliste, élégante et ultra-épurée conçue pour Windows. Améliorez votre productivité avec un style inspiré de l'esthétique Apple.

![Icône de l'application](cafe.png)

## ✨ Fonctionnalités

- **Minuteur de Productivité** : Cycles de travail personnalisables.
- **Gestion des Pauses** : Alternance automatique entre sessions de travail, pauses courtes et pauses longues.
- **Interface Apple-Style** : Un design épuré "Premium Light Mode" avec une typographie soignée.
- **Entièrement Personnalisable** :
  - Durée des sessions de travail.
  - Durée des pauses courtes et longues.
  - Nombre de cycles avant la pause longue.
- **Alertes Sonores** : Notification audio à la fin de chaque cycle.
- **Notifications Natives** : Intégration complète avec le système de notifications Windows.
- **Fenêtre Sans Cadre** : Une interface moderne déplaçable partout sur votre écran.

## 🚀 Installation

Vous pouvez télécharger la dernière version de l'application dans la section [Releases](https://github.com/votre-utilisateur/votre-depot/releases).

1. Téléchargez le fichier `Pomodoro Setup 1.2.0.exe`.
2. Lancez l'installateur.
3. L'application sera installée et un raccourci sera créé sur votre bureau.

## 🛠️ Développement (Local)

Si vous souhaitez modifier ou compiler l'application vous-même :

### Prérequis
- [Node.js](https://nodejs.org/) (version 18 ou supérieure recommandée)
- npm (installé avec Node.js)

### Installation des dépendances
```bash
npm install
```

### Lancer l'application en mode développement
```bash
npm start
```

### Compiler le code TypeScript
```bash
npm run build
```

### Créer l'exécutable Windows
```bash
npm run dist
```
L'exécutable sera généré dans le dossier `build/`.

## 🎨 Technologies utilisées

- **Electron** : Framework pour créer des applications de bureau.
- **TypeScript** : Pour un code robuste et typé.
- **HTML5 / CSS3** : Design sur mesure et responsive.
